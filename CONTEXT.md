# Context

## Glossary

- **Local SEO (Primary Traffic Source)**: Traditional search engine optimization targeting local search intent (Google Local, Maps). Drives the core content architecture and layout of the site for immediate, high-intent lead generation.
- **AEO / GEO (Secondary Traffic Source)**: Answer Engine Optimization / Generative Engine Optimization. Implemented behind-the-scenes using structured FAQ and Entity Schema (Organization/LocalBusiness) to secure AI citations without compromising the visual user experience.
- **Premium Conversion UI (Design System)**: A user interface that balances high-end aesthetic trust-signals (curated green palettes, modern typography) with straightforward, fast, and accessible conversion paths (e.g., persistent contact CTAs).
- **Internationalization (i18n)**: Full multi-language support from day one using dynamic `/[lang]/` routing for German (de), English (en), and Turkish (tr).
- **Content Management**: Content is hardcoded via JSON dictionaries and MDX to maximize performance and minimize MVP infrastructure complexity. No Headless CMS.
